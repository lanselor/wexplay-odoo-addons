# Reception inspection signature integration

Approved 2026-10-17. Extend reception only with saved description, tag names and
both annotated faces if either has marks. Empty inspection adds no block. Capture
composed diagrams, device type and console format with the request, so later edits
to repair data, catalog names or SVG assets cannot alter the displayed content.
Draft refresh is permitted. Queued/presented content is frozen; cancel and resend
to capture changes. Signed content/PDF cannot be rewritten. Historical documents
without the inspection key stay unchanged. Kiosk and PDF use the same snapshot.
Reception inspection starts on a new PDF page before the signature block. Keep
existing DMS SIGNATURES storage, consent options, asynchronous queue and access
rules. Delivery receives no new inspection section. No new persistent fields.
